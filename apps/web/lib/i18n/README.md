# `apps/web/lib/i18n`

**Overview.** User-facing copy: UI strings and the error messages that tell people what happened and what to do.

## What's here

| Path | What it is |
| --- | --- |
| [`en.ts`](en.ts) | English UI strings |
| [`errors.ts`](errors.ts) | Error codes mapped to what happened and what to do |

## Extending

Every new API error code needs an entry in `errors.ts` (see the [`guided-experience`](../../../../.agents/skills/guided-experience/SKILL.md) skill).
