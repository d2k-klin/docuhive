# `assets`

**Overview.** Images used by the README and the documentation. App screenshots use synthetic data only.

## What's here

| Path | What it is |
| --- | --- |
| [brand/](brand/README.md) | The Mr.D mascot files, under their own licence |
| [screenshots/](screenshots/README.md) | Reviewed app screenshots and how to refresh them |
| [docuhive-system-architecture.svg](docuhive-system-architecture.svg) | Editable system map for the technical blog; dashed amber outlines mark incomplete parts |

| [docuhive-architecture-handwritten.prompt.txt](docuhive-architecture-handwritten.prompt.txt) | Content/style prompt for the handwritten illustration; the final edit adds its vector/query connection |

## Extending

Keep images small, give them descriptive filenames and real alternative text, and link them from the docs that use them. Check every image for personal data and credentials before adding it.
